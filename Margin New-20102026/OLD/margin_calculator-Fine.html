Endpoint: POST https://secure.aetramtrades.in/apimarketdata/instruments/calculator/position — called directly from your browser, no key required. If the browser blocks the request (CORS), the status line above will say so — that means the endpoint isn't set to accept requests from wherever this file is opened from, and needs to be called from a page served on an allowed origin instead.

Data files — both live in the same folder as this HTML file and are read fresh every time the page opens: contract.txt (NSE F&O — drives Index & Stock) and mcx_bhavcopy.csv (MCX daily bhavcopy — drives Commodity; rename each day's download to this exact filename). MCX prices are taken straight from the bhavcopy's ClsPric column, no scaling. MCX lot sizes come from a fixed table in the code (the bhavcopy's own lot-size column isn't populated), so update that table if MCX changes a lot size.

Commodity legs are sent with Exchange: "MCXFO" — this follows the same NSEFO/MCXFO pattern as your brokerage calculator, but I haven't been able to confirm it against the live endpoint, so double check the very first commodity calculation against a known figure.

Margin benefit isn't returned by the engine directly, so it's derived here: each leg is also priced standalone (its own Portfolio call), those totals are summed, and margin benefit = sum of standalone totals − combined portfolio total — the amount your hedged/offsetting positions are saving you versus holding each leg on its own.
